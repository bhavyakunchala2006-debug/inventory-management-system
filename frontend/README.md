# Inventra Frontend Client

Modern, responsive glassmorphic React dashboard for Inventra Inventory Management System built with Vite & Tailwind CSS.

## Features

- **Auth**: JWT Authentication with protected routes and role-based views.
- **Dashboard**: Real-time stock metrics, Chart.js breakdown by category, low stock warnings, and recent transaction log timeline.
- **Product Management**: Search, filter, CRUD modal forms, and stock movement adjustments (Stock In / Stock Out).
- **Categories & Suppliers**: Complete management interfaces.

## Running Locally

```bash
npm install
npm run dev      # Start Vite dev server on port 5173
npm run build    # Verify production build
```
