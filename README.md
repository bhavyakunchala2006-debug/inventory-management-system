# Inventra - Full-Stack MERN Inventory Management System

Enterprise-grade Full-Stack Inventory Management System built with clean architecture, React, Express, and MongoDB.

## Project Structure

```text
inventory-management/
├── backend/           # Node.js, Express, MongoDB, JWT, Helmet, Multer
└── frontend/          # React (Vite), Tailwind CSS, Context API, Chart.js
```

## Quick Start

1. Start Backend:
   ```bash
   cd backend
   npm install
   npm run seed
   npm run dev
   ```

2. Start Frontend:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. Access the web app at `http://localhost:5173` with demo credentials:
   - **Email**: `admin@inventory.com`
   - **Password**: `password123`
